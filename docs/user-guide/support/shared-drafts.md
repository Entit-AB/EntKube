# Drafts

## Your own note is saved as you type

What you type in **Add a note** is saved on the server about a second after you stop. If you
reload the page, lose the connection, or come back tomorrow, it's there when you open the note
again. *Draft saved …* under the box says when. Only you see it. It's removed when you add the
note, or when you empty the box.

## Leaving a note for a colleague

**Save as shared draft** under the note leaves it on the ticket for somebody else to finish. A
ticket has one shared draft. If one already exists, the first press tells you whose it is, and
pressing **Replace the shared draft** overwrites it. Overwriting is final.

Anyone working the ticket sees **Draft available — left by …** among the actions:

- **Preview** shows the text and whether it was marked for the customer.
- **Load into the note** puts it in your note box. If you've already typed something there, you're
  asked first.
- **Delete the draft** removes it.

When a note made from a loaded shared draft is added, the shared draft is deleted automatically.

## Half-filled new tickets

In **New ticket**, **Shared drafts** on the right lists half-filled tickets saved by anyone in the
tenant. Give the form a name and click **Save** to add yours. Saving a loaded draft under the same
name updates it, and a new name makes a copy. **Load** fills the form (asking first if you've
started), and creating the ticket removes the draft it came from.

Drafts are never part of a ticket's history. Nothing in one has been sent or recorded until the
note or ticket is actually added.
