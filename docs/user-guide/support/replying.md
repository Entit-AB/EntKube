# Replying by mail

**Reply** on a ticket opens the composer. Write the mail with the toolbar (bold, italic, lists,
quotes, code, links) and click **Send**.

## Reply, reply all, forward

| | Goes to | On the history | Counts as the first response |
|---|---|---|---|
| **Reply** | The reporter and the customer's §14.1 technical contact and deputy | Visible to the customer | Yes |
| **Reply all** | The same, with copies to everyone else on the customer's last mail (tick who) | Visible to the customer | Yes |
| **Forward** | The addresses you enter, such as a supplier | Internal | No |

Everyone on a mail sees who else it went to, as with a mail from your own client. The subject
carries the ticket's reference, so answers come back to this ticket.

If the mail can't be sent, what you wrote is put on the history as an internal entry, so it
isn't lost, and the response clock keeps running, because the customer hasn't heard from you.

## Text modules and quoting

Type `::` in the composer to pick a text module. It replaces what you typed after the colons,
with its placeholders filled in from the ticket.

**quote**, next to a note in the history, adds that note to the mail as a quotation, headed by
who wrote it and when. The composer opens first if it isn't already open.

## Attachments

Under the editor, tick any of the ticket's stored files to send with the mail. Internal files are
marked *(internal)*, so check before you send one. Add new files in the ticket's
[Attachments](attachments.md) card first.

## Mail from customers

A mail that arrived as HTML is shown formatted on the ticket, as the description of a ticket it
opened or as its entry in the history. It is cleaned by the same rules as what you send:
formatting, lists, quotes, code and links stay, but **images are never shown**, so a tracking
pixel in a customer's mail never reports that you read it. A picture pasted into the mail, such as
a screenshot, is kept as a file in the ticket's [Attachments](attachments.md) card. A very large
HTML mail, such as a newsletter, is shown as its text.

Search, the triage phrases, the cut line in replies and the customer portal all read the mail's
text, exactly as before.

## What is sent

What you write is cleaned before it's sent or stored. Formatting, lists, quotes, code and
`http`, `https` and `mailto` links are kept. Pasted images, colours, fonts, scripts and anything
else are removed, so send files as attachments. The mail carries an HTML version and a plain-text
version of the same content.

After sending, you're asked how long it took (see [Time accounting](time-accounting.md)).
